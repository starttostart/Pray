    Adding it to Outlook

    • Outlook on the web or new Outlook: Calendar, then Add calendar, then Upload from file. Pick the downloaded file and the calendar to add the events to.
    • Classic Outlook for Windows: File, then Open & Export, then Import/Export, then "Import an iCalendar (.ics) or vCalendar file". Choose Import to put the events in your main calendar so they show as Busy to others.
    • Outlook for Mac: File, then Import, or drag the file onto the calendar.

    Re-importing the same dates for the same place updates the existing events rather than duplicating them in Outlook clients that honour event IDs. Times are computed in your browser with adhan-js; city search uses the Open-Meteo geocoding API.
